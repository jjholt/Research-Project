\subsection{Calculating damping ratio}
We will use the logarithmic decrement, $\delta$, to find the damping ratio, $\zeta$:
\begin{align}
    \zeta = \frac{\delta}{ \sqrt{\delta^2 + {(2\pi)}^2} } \text{ where } \delta = \ln\frac{x_{n}}{x_{n+1}} 
\end{align}
