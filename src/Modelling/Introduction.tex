The designed experimental setup aims to have an ITAP ``in a vacuum'', so we can characterise its behaviour before any interaction with bone or soft tissue.
To do so, we simulate the setup seen in figure \ref{fig:experimental-setup}, with the following setup: \begin{enumerate}
    \item It is held in place by a vise at the stem, \SI{20}{mm} away from the collar, allowing only for rotation about the X-axis.
    \item The periodic load is applied on the spigot at a given offset (``Load offset''). Default is \SI{1}{mm}.
    \item The default periodic load is a cosine function with frequency \SI{100}{Hz}, amplitude \SI{0.2}{mm} and duration of 6 periods, as per figure \ref{eq:cos-vals}.
\end{enumerate}

\subsection{Simplifications}
In order to reduce computational times, we simplify the model in a couple of ways: Remove most complex features, e.g. fillets, pores in the flange; and remove the flange altogether.
In first instance we are building up to the interaction with bone, and so it is reasonable to remove the part of the device that interacts with soft tissue.
Ultimately, we expect this to introduce a reasonable amount of error, particularly for the collar, which we can later on quantify.
This simplification can be seen in Figure \ref{fig:simplification}.
