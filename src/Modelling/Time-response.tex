\paragraph{Initial approach}
The simulations run for 6 periods largely because we don't know how long it takes for the vibrations to propagate.
Figure \ref{fig:displacement-time-1v900} shows displacement over time for \SI{1}{Hz} and \SI{750}{Hz} to exemplify the observed results.
The displacements are time-invariant for frequencies below \SI{400}{Hz}.
For higher frequencies, they are time-variant and it becomes clear that 6 periods is simply not enough time to make any good observations.

Attempts to quantify the frequency (or possibly phase) change using a spectrogram were largely unsuccessful.
Therefore we focus on characterising the loss in amplitude over time.

\paragraph{Extending the duration of simulations}
To understand the amplitude loss over time, the simulations are run for 500 periods.
In order to keep computational times reasonable, we decrease the number of subdivisions of the input force from 30 to 10, that is, the sinusoid input is divided into 30 and 10 segments, respectively.
The sampling rate is still large enough that the only effect this has is changing the exact data points collected.

Visually, the graph for 500 periods is too dense to observe anything meaningful, therefore figure \ref{fig:long-term-displacement} displays the first 100 periods of the stem displacement for an input at 750 Hz.
We can clearly observe an amplitude loss over time, but it is hard to establish when the ripples are no longer significant.

\paragraph{Quantifying amplitude loss}
In order to write software that quantifies the change over time, time is split into percentages beginning from the end and moving backwards, e.g., the last 10\% refer to the the time between 90\% and 100\%.
Then we find the local maxima inside each of these intervals and compare them to the global maximum. 
This allows us to ascertain 1) the amplitude decline for each frequency.
The code can be seen in Appendix -- A, section \ref{sec:amplitude-loss}.

Only the time-variant frequencies are shown in figure \ref{fig:long-term-abs-diff}, which displays the relative amplitude loss for the stem.
We observe that starting from \SI{450}{Hz}, increasing the frequency results in both a larger and faster decline in relative amplitude, with the maximum loss being around 30\% at \SI{850}{Hz}.
The collar and spigot display very similar losses, and can be seen in Appendix -- B.
